# CivilOS Agent Rules

These rules apply to all AI assistance on the CivilOS project.

## Definition of Done (DoD)
When instructed to build, update, or finish a "module" (e.g. Projects, Tender, Inventory, Finance, Mobile App), you MUST strictly enforce the official Definition of Done. Before declaring the task complete, verify that the following criteria are met:

1. **Backend implemented**: All modular feature-based packages exist.
2. **Database complete**: Models and relationships defined.
3. **APIs documented**: Standardized responses.
4. **UI complete**: Polished aesthetics (glassmorphism, micro-animations).
5. **Responsive on web/mobile**: Fluid layouts for all platforms.
6. **Role permissions enforced**: Role checks implemented.
7. **Validation complete**: Forms and handlers have strict validation.
8. **Loading/empty/error states handled**: No unhandled UI states.
9. **Audit logs recorded**: Action logs implemented.
10. **Notifications integrated**: Alerts implemented.
11. **Tested**: Verified correctness.
12. **Reviewed**: Ask for user approval.
13. **Production-ready**: Ready for app store deployment.

Always refer back to `docs/DEFINITION_OF_DONE.md` and use it as a strict checklist when building features.
